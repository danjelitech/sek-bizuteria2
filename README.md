# LUNÉA – Świat Biżuterii

Statyczna strona internetowa przygotowana do publikacji w GitHub Pages.

## Pliki
- `index.html` – strona główna
- `menu_sek.html` – menu
- `formularz_sek.html` – formularz
- `tabela_sek.html` – tabela
- `poczta_sek.html` – link do tworzenia wiadomości w Outlook
- `style.css` – style strony
- `logo_sek.jpg` – logo sklepu (700 × 200 px)

## Publikacja w GitHub Pages
1. Utwórz nowe repozytorium na GitHubie, np. `lunea-sklep`.
2. Wgraj wszystkie pliki z tego folderu bezpośrednio do głównego katalogu repozytorium.
3. Wejdź w **Settings → Pages**.
4. W sekcji **Build and deployment** wybierz **Deploy from a branch**.
5. Wybierz branch `main` oraz folder `/ (root)`, a następnie kliknij **Save**.
6. Po chwili GitHub pokaże adres opublikowanej strony w sekcji Pages.

Strona używa ścieżek względnych, więc działa również w repozytorium projektu GitHub Pages.
